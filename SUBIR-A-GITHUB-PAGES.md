# Subir la web a GitHub Pages

1. En GitHub crea un repositorio público llamado `Where-is-my-car` (en tu cuenta/organización super-ia).
2. Sube `index.html`, `privacy.html` y `logo.png`.
3. Settings → Pages → Source: "Deploy from a branch" → `main` / root → Save.
4. En 1-2 minutos estará en `https://super-ia.github.io/Where-is-my-car/` y la privacidad en `.../privacy.html`.
